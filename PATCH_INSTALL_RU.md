# Daamky 1.0 RELEASE — первый этап интерфейса

Это обновление исходников поверх присланного `celkazxc.zip`. Оно переводит namespace проекта на `daamky`, поэтому обновлять нужно не отдельные `.java`-файлы, а заменять исходную папку `src` целиком.

## Установка обновления

1. Сделай резервную копию своего проекта.
2. Распакуй архив в корень проекта.
3. Замени папку `src` содержимым из архива. В ней уже находятся Java-пакеты `daamky`, `fabric.mod.json`, mixin-конфигурация и ресурсы в `assets/daamky`.
4. Замени `build.gradle`, `gradle.properties` и `settings.gradle` файлами из архива.
5. Убедись, что рядом с проектом остаются папки `fonts` и `tools`, также включённые в архив.
6. Запусти workflow **Daamky Build** в GitHub Actions. После успешной сборки JAR появится в Artifacts.

## Переключение интерфейсов

- По умолчанию используется Daamky Interface.
- `.itest set 1` — Celestial Legacy.
- `.itest set 2` — Daamky Interface.
- `Right Shift` открывает выбранный ClickGUI.

Выбранный режим сохраняется в `config/daamky/interface.txt`.

## Важно

Это исходники первого этапа, а не готовый проверенный JAR. В этой среде нет установленного Gradle и нельзя скачать зависимости, поэтому полноценная Gradle-сборка и проверка в игре здесь не выполнялись. Workflow добавлен для сборки проекта в GitHub Actions.

Игровые модули не расширялись. Перенос новых возможностей отложен до утверждения интерфейса.
